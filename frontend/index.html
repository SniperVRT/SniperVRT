⚠ Live trading (LOCKED by default)

Live execution is gated by FOUR independent locks. ALL must be true before any live order could be considered:

  • configs/live.yaml locked: false — currently {{ liveStatus?.locked_config ? 'LOCKED' : 'unlocked' }}
  • API keys present in env — currently {{ liveStatus?.has_api_keys ? 'YES' : 'NO' }}
  • Governance readiness ≥ 80 — currently {{ liveStatus?.live_readiness_score?.toFixed(1) }}
  • Human unlock (this UI) — currently {{ liveStatus?.human_unlocked ? 'UNLOCKED' : 'LOCKED' }}

Even when all four are true, this build ships without any code that actually places live orders — the LiveGate is the chokepoint a future executor must call through.

Wallet / account

This build does not connect to a live wallet. To prepare for the future:

  1. Set SNIPER_EXCHANGE_API_KEY and SNIPER_EXCHANGE_API_SECRET in .env.
  2. Choose exchange in configs/live.yaml (default: binance, sandbox: true).
  3. Keep locked: true until governance approves.

Secrets are never read from the repo and never printed to logs.
